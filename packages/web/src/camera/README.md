# camera

## Overview

Reading the camera of a MapLibre map as a `MapCamera`, and what it shows as a `MapViewport`.

## Components

| Component | Responsibility |
|-----------|----------------|
| [readCamera.ts](readCamera.ts) | Camera of a map, with the longitude wrapped |
| [readViewport.ts](readViewport.ts) | Size, corners and extent of what a map shows |
