# src

## Overview

Source of `@web-map/core`.

## Components

| Component | Responsibility |
|-----------|----------------|
| [basemap](basemap) | Basemap types, their attribution and terms, and validating definitions |
| [camera](camera) | Positions, the camera of a map, and the viewport and extent it shows |
| [terrain](terrain) | Terrain types, how their tiles encode elevation, and validating definitions |
| [catalog](catalog) | Open basemaps and terrains by provider |
| [projection](projection) | Web Mercator meters, and meters per pixel at a zoom level |
| [tile](tile) | Web Mercator tile grid and tile URLs |
